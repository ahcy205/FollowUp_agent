- 원칙: 업무 규칙 10가지와 서버 동작은 그대로. 백엔드는 읽기 전용 API 3개만 더한다(사용자 승인).

## Task 1: 읽기 전용 API 3개 (백엔드)
- [x] ① `GET /api/activity?limit=` — 메일 업무의 최근 처리 기록. 입력 · 결과 값은 내보내지 않는다.
- [x] ② `GET /api/knowledge/sources/{id}` — 자료 상세(덩어리 줄 · 의심 표시 · 참고한 답장). 다른 사용자 자료는 404. 스위치가 꺼져도 볼 수 있다.
- [x] ③ `POST /api/knowledge/search` — 검색 시험. 스위치 꺼짐 409, 검색어 1~200자, 분당 30회.
- [x] 테스트: `test_activity_api.py`, `test_knowledge_detail_search.py`. 전체 통과.

## Task 2: 화면 (프론트엔드)
- [x] 디자인 체계: `styles.css` 전면 교체(흰 · 연회색 바탕, 남색, 인디고 강조, 상태색 3가지, 그라데이션 없음).
- [x] 틀: 왼쪽 사이드바(홈 · 받은 업무 · 후속 관리 · 자료실 · 설정, 받은 업무 · 후속 관리 개수 표시). 980px 이하 아이콘 막대, 720px 이하 아래 탭 막대.
- [x] 홈: 숫자 칸, 지금 처리할 업무, AI 처리 상태, 새로 가져온 메일, 최근 업무 활동(API ①). (→ 변경 #1)
- [x] 받은 업무: 목록 + 상세 패널 3단, `/inbox/:id`, 예전 `/tasks/:id`는 이동. 탭 · 묶음 그대로. 목록 검색, `j` · `k` · `Esc` · `/` · `?`. (→ 변경 #2, #3)
- [x] 업무 상세 패널(`TaskPanel`): 예전 업무 상세의 모든 기능(SSE, 내용 바뀜 끄기, 합치기 이동, 캘린더 다시 시도, 답장 입력 상태). AI 정리 · 직접 정함 표지. (→ 변경 #4)
- [x] 답장 초안: 발송 체크리스트(빈칸 · 근거 없는 값 · 내부용 값 · 참고한 자료 · 받는 사람 · 고친 내용), 받는 사람 잠금 표시.
- [x] 후속 관리: 답이 없어요 · 상대가 내용을 바꿨어요 · 아직 답장하지 않았어요 · 답 기다리는 중.
- [x] 자료실: 표, 상세 패널(API ②), 검색 시험(API ③), 공유 등급 바꾸기 · 지우기 확인.
- [x] 설정: Google 연결 상태 · 권한, 기능 스위치(읽기 전용), 브라우저 알림. (→ 변경 #5)
- [x] 빌드 · lint.
