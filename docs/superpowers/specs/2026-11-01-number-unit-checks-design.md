# 숫자 단위(만 · 천 · 억) 비교와 경고 값 표시 설계

- 작성일: 2026-11-01
- 상태: 사용자 검토 대기
- 계기: 전체 UI 검토에서 "근거 없는 값 30"이 오탐으로 보였다. 확인해 보니 오탐이 아니었다. 초안의 "30만 원 이상 무료 배송"은 메일 · 자료 어디에도 근거가 없다. 다만 두 가지 약점이 드러났다(사용자 결정: 둘 다 고친다).

## 1. 문제
1. **값 칩이 숫자만 보인다.** "30만 원"이 "30"으로, "1,500원"이 "1500"으로 보인다. 사용자는 어느 문장의 어떤 값인지 알기 어렵고, 틀린 경고처럼 보여 확인 없이 체크하게 된다.
2. **단위 표기가 다르면 다른 숫자로 본다.** 근거가 "300,000원"이고 초안이 "30만 원"이면 30 ≠ 300000이라 근거 없음으로 경고한다(진짜 오탐). 반대로 내부용 자료의 원가 "88000"이 초안에 "8만 8천 원"으로 들어가면 내부용 값 검사를 빠져나간다(유출 경로).

## 2. 바꾸는 것 (`backend/app/mail/draft_checks.py`의 토큰 나누기)
### 2.1 단위 숫자를 하나의 값으로 (비교 키)
- 숫자 바로 뒤(띄어쓰기 0~1칸)에 `억` · `만` · `천`이 붙으면 곱해서 하나의 숫자 키로 만든다.
  - "30만" → 300000, "1.5만" → 15000, "3천" → 3000, "2억" → 200000000
  - 이어 쓴 큰 단위부터 작은 단위까지 하나로 합친다: "1억 2천만" → 120000000, "8만 8천" → 88000, "3만 5천 500" → 35500
- 소수 결과가 정수가 아니면(예: "1.23천" → 1230은 정수, "0.0001만" → 1) 정수로 떨어질 때만 단위 키로 보고, 아니면 지금처럼 숫자 그대로 둔다 **(내 판단)**.
- 날짜(월 · 일) · 전화 · 쉼표 처리 규칙은 그대로다.
- 같은 함수(`tokens`, `token_spans`, `supported_keys`)를 쓰는 곳에 함께 적용된다. 모두 같은 방향으로 좋아진다.
  - 근거 없는 값 경고: "30만 원" ↔ "300,000원"이 같은 값
  - 자료 인용 확인(`draft_sources`): 자료 줄 "300000"과 초안 "30만"이 맞는다
  - 내부용 값 검사: 초안 "8만 8천 원"이 내부용 "88000"으로 잡힌다
  - 자료 검색(`search`)의 숫자 맞추기: 검색어 "30만"이 "300,000"이 든 줄에 맞는다

### 2.2 보이는 값에 단위까지 (보일 글)
- 경고 칩에 보일 글(`shown`)은 원문 그대로 쓰고, 바로 뒤의 단위 말을 붙인다: `원 · 개 · % · 명 · 대 · 건 · 회 · 박스 · 세트 · 장 · 권 · EA · kg · g · 시간 · 분 · 주`.
  - 예: "30만 원", "1,500원", "100개", "3주"
- 비교에는 쓰지 않는다(표시만). 같은 값이 여러 번 나오면 첫 번째 보일 글 하나만 남긴다(지금과 같음).
- 화면(`ReplyDraftCard`)은 받은 글을 그대로 보여 주므로 바꾸지 않는다.

## 3. 바꾸지 않는 것
- 경고가 보내기를 막는 규칙(확인해야 보내기, 서버 409), 저장 형식(`warnings.unsupported`는 문자열 목록), API.
- 이미 저장된 초안의 경고는 다음 저장 · 다시 만들기 · 자료 변경 확인 때 새 규칙으로 다시 계산된다. 마이그레이션 없음.
- LLM 프롬프트 · 호출. 실제 메일 데이터 전송 범위.

## 4. 위험과 비용
- "만"이 단위가 아닌 경우: 숫자 바로 뒤의 "만"은 거의 단위다("2만큼"은 드묾). "10개만"처럼 다른 말 뒤의 "만"은 숫자에 붙지 않아 영향이 없다 **(내 판단)**.
- 키가 바뀌므로 내부용 값 색인 · 검색 결과가 조금 달라진다(더 잘 맞는 방향). 색인은 요청마다 다시 계산되어 저장된 값이 없다.
- 틀렸을 때 비용: 단위가 아닌 "만"을 곱하면 근거 없는 값 경고가 하나 더 뜬다(보내기 전에 사용자가 확인). 놓치는 쪽이 아니라 더 경고하는 쪽으로 틀린다.

## 5. 확인
- 단위 테스트: 단위 숫자 키, 이어 쓴 단위, 소수, 단위 말 붙은 보일 글, 기존 날짜 · 쉼표 테스트 그대로 통과.
- `draft_sources` · 내부용 값 · 검색 테스트에 단위 표기 사례 추가.
- LLM 프롬프트는 바꾸지 않으므로 실제 LLM 스모크는 돌리지 않는다.
