# 데모 모드 분리 설계

상위 설계: [`2026-10-10-gmail-calendar-design.md`](2026-10-10-gmail-calendar-design.md) 7단계 "데모 모드 분리"와 설정표의 `DEMO_MODE`를 6단계 전에 앞당긴다.

## 왜 지금

- 해커톤 데모 데이터(가상 고객 · 문서 · 메일 · 데모 업무)와 데모용 기능이 실제 메일 업무와 섞여 있다.
- **Demo Reset이 위험하다.** 지금은 누르면 Gmail 메일은 남기지만 메일 업무(할 일 · 기한 · 직접 고친 내용)를 모두 지우고 데모 데이터를 다시 만든다.
- 6단계(답장 발송)를 점검할 때 가상 고객 · 시뮬레이터가 섞이면 무엇이 실제인지 헷갈린다.

## 목표

1. `DEMO_MODE` 스위치 하나로 데모 기능 전체를 켜고 끈다. **코드는 지우지 않는다.** 나중에 발표 · 시연이 필요하면 켠다.
2. 꺼져 있으면 사용자 눈에 데모 흔적이 없다.
3. 켜져 있어도 Demo Reset이 실제 메일 업무를 지우지 않는다.

## 하지 않는 것

- 해커톤 Agent 코드(목표 입력 · 도구 호출 · 승인) 삭제. 상위 설계대로 "보조 기능"으로 남긴다. 목표 입력을 메뉴 안쪽으로 옮기고 `contacts`로 수신자를 고르는 일은 7단계에 그대로 둔다.
- 업무 상세의 Agent Activity · Timeline 패널 정리. 화면 전체 다듬기(UI/UX 개선) 때 함께 본다.
- 데이터 삭제. 기존 데모 데이터는 2026-10-27에 이미 수동으로 지웠다(백업 `dev.db.bak-20261027b`).

## `DEMO_MODE`가 꺼져 있을 때

| 부분 | 동작 |
|---|---|
| 회원가입 | 데모 데이터를 만들지 않는다. 빈 계정으로 시작한다. |
| 서버 시작 시 데모 계정(`DEMO_USER_PASSWORD`) | 만들지 않는다. |
| `POST /api/demo/reset`, `POST /api/tasks/{id}/simulate-reply` | 404 |
| 업무 상세 `can_simulate_reply` | 항상 false |
| 상단 메뉴 | "Demo Reset" 버튼과 "워크스페이스 데이터" 메뉴를 숨긴다. `/workspace`로 들어오면 첫 화면으로 보낸다. |
| 업무 상세 | 회신 시뮬레이터를 숨긴다. |
| 로그인 화면 문구 | 해커톤 문구("목표만 말하세요…")를 메일 Agent 소개로 바꾼다. 예: "업무 메일, 놓치지 않게." / "Gmail의 업무 메일을 정리하고, 할 일과 기한을 챙기고, 캘린더에 올립니다." |

워크스페이스 조회 API(가상 고객 · 문서 목록)는 그대로 둔다. 데이터가 없으면 빈 목록이고, 목표 입력 Agent의 도구가 쓴다.

## `DEMO_MODE`가 켜져 있을 때

지금과 같다. 단, **Demo Reset은 데모 데이터만 지운다.**
- 지우는 것: `origin`이 `seed` · `user` · `agent`인 업무와 그 기록 · 실행 · 승인, Gmail이 아닌 메일, 고객, 문서
- 남기는 것: 메일 업무(`origin=mail`)와 그 기록, Gmail 메일, Google 연결
- 남긴 메일 업무 · 메일이 지워질 고객을 가리키면 연결만 끊는다.

## 프론트가 스위치를 아는 방법

로그인 사용자 정보(`GET /api/auth/me`, 로그인 · 가입 응답)에 `demo_mode: bool`을 더한다. 화면은 이 값으로 메뉴 · 시뮬레이터를 숨긴다. 서버가 404로 막으므로 화면 숨김은 편의일 뿐이다.

## 기본값 (사용자 결정, 2026-10-27)

상위 설계는 "개발 기본 `true`, 운영 기본 `false`"였다.
**결정:** 기본값을 `false`로 바꾼다(사용자 승인). 개인 프로젝트로 바뀌었으므로 데모가 필요할 때만 `.env`에 `DEMO_MODE=true`를 적는다. 테스트는 `conftest.py`에서 `true`로 고정해 기존 데모 테스트를 그대로 돌리고, 꺼짐 동작 테스트를 따로 둔다.

## 테스트

- 꺼짐: 가입해도 업무 · 고객 0개, 데모 API 404, `can_simulate_reply` false, `me.demo_mode` false
- 켜짐: Reset 뒤 메일 업무 · Gmail 메일 · Google 연결이 남고 데모 업무는 다시 생긴다. 메일 업무가 지워질 고객을 가리켜도 오류 없이 연결만 끊긴다.
- 브라우저: 꺼짐 상태에서 메뉴 · 시뮬레이터가 안 보이고 `/workspace`가 첫 화면으로 간다. 5단계에서 남은 점검(업무로 처리, 휴대폰 너비)도 함께 본다.
